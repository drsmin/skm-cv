# D-004. 이력서 내용은 resume/data.json 하나에, 페이지는 그것을 그린다

**결정:** 이력서·포트폴리오 내용을 `resume/data.json` 에 두고, 보기(`resume/index.html`)와
편집(`resume/edit.html`) 페이지가 그 파일을 읽는다. 빌드·외부 라이브러리 없이 바닐라 JS.
형식·스키마는 `docs/resume-design.md`.

**이유:** 원본 페이지는 Mobirise 가 만든 HTML 이라 내용과 마크업이 섞여 수정이 번거롭다.
내용을 데이터로 떼면 HTML 을 몰라도 고칠 수 있고, GitHub Pages 에 그대로 올라간다.
