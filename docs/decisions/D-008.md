# D-008. 공개 이력서의 휴대폰 번호는 가운데를 가린다 (원본 포함)

**결정:** `resume/data.json`·PDF·원본 `cv.html` 모두 `+82 10-****-7377` 로 보인다. D-003(원본 보존)의 예외로
원본은 번호 한 줄만 바꿨다. 가린 번호에는 전화 링크를 만들지 않는다. 번호 전체가 들어간 제출용 PDF 는
요청 시 프로젝트 안에서만 만들고 공개 저장소에는 올리지 않는다.

**이유:** 사용자 선택(2026-10-20). 저장소·사이트가 공개라 번호가 수집될 수 있다. git 기록에는 번호가 남아 있으며,
지우려면 기록 재작성(force push)이 필요해 사용자가 원할 때만 한다.
