# D-007. PDF 는 GitHub Actions 가 headless Chrome 으로 미리 만든다

**결정:** `scripts/build-pdf.mjs`(Playwright)가 보기 페이지를 고정 설정으로 PDF 로 찍어 `resume/pdf/` 에 두고,
`.github/workflows/resume-pdf.yml` 이 master 의 `resume/` 변경마다 다시 만들어 커밋한다. 보기 페이지는 그 파일을 내려준다.
폰트가 안 뜨거나 페이지 오류가 있으면 스크립트가 실패한다(잘못된 PDF 를 올리지 않는다).

**이유:** 사용자 요청(2026-10-20) — 브라우저 인쇄로 만들면 여백·머리글/바닥글·배율 설정에 따라 결과가 달라진다.
D-006 의 인쇄 CSS 는 그대로 쓰고, PDF 만드는 쪽의 설정을 서버에서 고정한다. 클라이언트 JS PDF(html2pdf 등)는
글자가 이미지로 들어가거나 한글 폰트 처리가 약해 쓰지 않았다.
