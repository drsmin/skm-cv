# D-006. 인쇄·PDF 는 브라우저 인쇄 + A4 인쇄 CSS, 폰트는 저장소에 둔 Pretendard 정적 subset

**결정:** PDF 는 서버 생성 없이 「PDF로 저장 · 인쇄」 버튼(브라우저 인쇄)으로 만든다. `@page` A4 + 인쇄 전용
CSS 로 쪽 나눔·쪽 번호를 맞춘다. 폰트는 Pretendard 정적 subset 4굵기를 `resume/fonts/` 에 직접 둔다.

**이유:** 사용자 요청(2026-10-20) — PDF 내보내기와 인쇄 최적화, 폰트 중요. 브라우저 인쇄는 글자가 선택되는
벡터 PDF 를 만들고 빌드가 필요 없다. CDN 폰트는 막히거나 늦게 뜨면 PDF 에 대체 폰트가 박히고, 가변 폰트는
Chrome PDF 에서 Type 3 로 박혀 정적 폰트로 바꿨다. 상세 `docs/resume-design.md` §3.
