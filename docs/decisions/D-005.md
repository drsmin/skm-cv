# D-005. 편집 페이지는 브라우저에서 GitHub API 로 바로 커밋, 토큰은 저장하지 않는다

**결정:** `resume/edit.html` 이 `resume/data.json` 을 GitHub Contents API(PUT)로 커밋한다. 토큰은
입력칸에서 저장 순간에만 읽고 localStorage·쿠키·변수 어디에도 남기지 않는다(새로고침하면 사라짐).
CSP 로 외부 스크립트를 막고 연결은 `'self'`·`api.github.com` 으로만 제한. JSON 내려받기도 둔다.

**이유:** 사용자 선택(2026-10-20). gh CLI 는 브라우저 페이지에서 쓸 수 없고, 로컬 편집 서버보다
어디서든 열 수 있는 쪽을 원했다. 권장 토큰: `drsmin/skm-cv` Contents 읽기·쓰기만 준 fine-grained.
편집 페이지는 공개 주소에 있지만 토큰 없이는 저장할 수 없다(`noindex`).
